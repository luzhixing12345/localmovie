# localmovie

通过局域网在手机/平板上浏览本地电脑视频

## 使用

本项目运行无需额外第三方库。首先修改 `config.ini`，把 `[video] directories` 改为你需要映射的视频目录；如有多个目录，使用英文逗号 `,` 分隔。

运行

```bash
python main.py
本机访问: http://127.0.0.1:8456/
局域网访问: http://10.20.71.231:8456/
按 Ctrl+C 停止服务
```

在手机或平板浏览器中打开程序输出的局域网访问地址即可。

> 需要保持电脑和手机/平板位于同一个局域网/Wi-Fi 下，也可以手机开热点给电脑使用。

页面会按原始文件夹结构展示目录和视频文件。目录内容按名称字典序排序，播放视频时支持浏览器拖动进度条。

## 功能说明

- 支持按配置目录浏览本地视频。
- 支持 HTTP Range 分段传输，浏览器可以边加载边播放，也可以拖动进度条。
- 支持同名 `.srt` 字幕自动加载，例如 `movie.mp4` 对应 `movie.srt`。
- 字幕会在服务端临时转换为浏览器支持的 WebVTT 格式。
- CSS、JS、HTML 模板已拆分到 `static/` 和 `templates/`。

## 相关问题补充说明

### 点击播放卡住？

项目已经使用 `preload="metadata"`，并且 `/video` 接口支持 HTTP Range 分段传输。

但是有一些 MP4 点击后直接卡住，需要等待很久才出现画面，并且在日志中可以看到 `206`，说明浏览器正在按片段读取视频，不是在一次性下载完整文件。

这是因为这些 mp4 格式并不规范，片段比较琐碎，导致需要缓存完整的mp4文件才能找到第一帧播放，笔者这里提供了一个py脚本用于修复相应的 mp4 文件

> 首先确保你的环境中已经安装了 ffmpeg

```bash
python tools/check_remux_mp4.py "G:\video"
```

该脚本会使用 "-movflags+faststart" 覆盖修复 mp4 文件，默认会处理某个目录及所有子目录下的所有 mp4 文件

该脚本默认是 dry-run，只会打印建议，不会修改文件。确认无误后可以真正执行重封装：

```bash
python tools/check_remux_mp4.py "G:\video" --apply
```

### 浏览器无法全屏播放 mkv？

这个和你使用的浏览器有关系，

### 为什么控制台会出现 WinError 10054？

浏览器播放视频时会频繁发起和取消 Range 请求。拖动进度条、缓冲策略变化、切换播放位置时，浏览器可能主动关闭旧连接。Windows 下这类断开可能显示为：

```text
ConnectionResetError: [WinError 10054]
```

当前代码已经把这类客户端断开当作正常结束处理，不会影响后续播放。

### 为什么不是 HTTP/3？

当前服务基于 Python 标准库 `http.server`，只支持 HTTP/1.1。HTTP/3 基于 QUIC，需要 UDP、TLS 1.3、证书和专门的服务器实现。

本项目的关键播放能力是 HTTP Range 分段读取，HTTP/1.1 已经可以满足。对于局域网本地播放，优先处理视频容器和编码兼容性，收益通常比切换 HTTP/3 更明显。

### 字幕为什么没有显示？

浏览器原生字幕轨道需要 WebVTT，本项目会把同名 `.srt` 临时转换为 WebVTT。

请确认：

- 字幕文件和视频同目录；
- 字幕文件名和视频主文件名一致；
- 示例：`movie.mp4` 对应 `movie.srt`；
- 播放器右下角字幕/CC 开关已启用。

脚本会尝试读取常见字幕编码：`utf-8-sig`、`utf-16`、`gb18030`、`big5`。
